# 多摩地区のそごうについて
wikipediaを出典とした記事です。許して。
## 


:::
つぎは終点、多摩センターです。サンリオピューロランドと多摩そごうはこちらです。
:::
どうやら車内で眠っていたようです。眺めがいいのでここは多摩モノレールの車内でしょう。
高架駅から降りて、連絡通路を抜けます。右手には八角形のガラスのシリンダーが見えます。
そごうでしょうか。バブルは弾けていないのでしょう。心なしか、駅前にもたくさんの人がいる気がします。
多摩そごうは三越を経てココリアになったはずですが、こちらではエレベーターガールはいないものの、元気に営業中なようです。
小田急線の改札口を通って、キティたちのステンドグラス的な装飾の施された紺色の改札を抜けます。
京王相模原線の橋本行きホームへエスカレーターを登ると、ちょうど橋本行きの特急電車がやってきました。
眠い目をこすりながら、乗り込みます。動き出した列車は扉をバタバタ言わせながら京王堀之内を通過して、南大沢に近づいています。
:::
つぎは南大沢です。首都大学東京と柚木そごうはこちらです。
:::
驚きました。そう。多摩センターの二駅隣なのにまたそごうがあるのです。
どうやらここのそごうは南大沢の旧地名である柚木という名前を店名としているようです。
このそごうは成績が酷すぎるのでそごうが潰れる前に撤退してしまい、存在したのは2年ほどであったと聞いていましたが、こちらでは元気なのでしょう。
ちなみに、そごうの入っていたガレリア・ユギはその後入っていたもう一つのテナント、忠実屋も撤退して、しばらくゴースト化したのちに、イトーヨーカドーが入ったようです。
話を元に戻して、電車は発車します。
さあ、多摩境を過ぎて、いよいよ終点橋本です。
:::
つぎは橋本、終点です。横浜線、相模線はお乗り換えです。
橋本そごうはこちらです。
:::
なんということでしょう。
南大沢から二つしか離れていないのにまたそごうが。
話によると、近鉄、京王、そごうで争って、京王の二倍の賃料を提示したというあのそごうが。
そごうが潰れて、話は流れ、土地はサティになったというあのそごうが、ここにも。
しかし、そごうがたくさんありますね。今、話題の異変ってやつなのでしょうか。
どちらにせよ、この世界線でも地主のせいなのか、
相模原線は相模中野まで伸びていないようなので、ここで電車は終点です。
なんの用でここまできたのかはあまり覚えていませんが、橋本まできたことだし、横浜線に乗れば思い出すかもしれません。
ちょうど列車がやってきたので、乗りましょう。
相原、八王子みなみ野、片倉と走って、絹の都、八王子です。
:::
つぎは、八王子、終点です。中央線はお乗り換えです。
:::
おや、もう終点です。東神奈川行きに乗ったはずが、急いでいたので間違えたのでしょう。
道理でいつもの駅と違うはずだ。
さあ、車窓の右側をのぞくと見覚えのあるマークが見えます。
丸の中に砂時計のようなマークが入っています。丸井でしょうか、大丸でしょうか。
いいえ、違います。エス、オー、ジー、オー、そごうです。
多摩地区でも古参店のそごうがあるではありませんか。
まさか、そんなはずが、あるのでしょうか、今日だけでも4回目、いやもっと見たような気もします。
多摩、柚木、橋本、八王子。ああ、四つもあります。
駆け足になって、中央線のホームに飛び込むと、快速の東京行きが滑り込みます。
そごうのロゴが上から私を見下ろすように見ています。

中央線は走ります。豊田、日野を過ぎるうちに、考えます。
なぜそごうはこんなにもあるのか。
なぜ私はそこに存在するそごうに違和感を抱いているのか。
なぜそごうに関する存在しないはずの記憶が私に語りかけてくるのか。
なぜ、と考えていると、多摩川が見えてきました。

:::
つぎは立川です。南武線、青梅線、多摩モノレールはお乗り換えです。
jr東日本立川そごうは当駅です。
:::
そごうがあります。そごうです。心の声もグランデュオになったはずだと私に語りかけます。阪急百貨店との提携がなってグランデュオになっていたはずだと言います。
なぜ私はそう考えるのでしょうか。なぜ私はそこに存在するはずのものが怖いのか。
なぜなのでしょうか。気がつくと階段を駆け上がっています。
改札も出ていたようです。額縁のような伊勢丹、赤い円柱の丸いオブジェ。
確かに見覚えのある景色なのに、なぜでしょうか。デッキを走ります。
モノレール駅に飛び込み、やってきた列車に駆け込むと、南の方向へ動き出します。
座席に座り込んだ私は、クランク状のカーブをゆっくり走る列車に対し、焦燥感を感じます。
疲れがたまっているのか、まぶたが重くなってきます。

end
